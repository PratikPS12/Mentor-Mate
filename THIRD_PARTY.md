# Third-Party Dependencies & Licenses

Mentor Mate adheres to strict license governance and legality standards.
No copyrighted student or publisher material is scraped or redistributed. All open-source packages are verified for compatibility, maintenance, and security.

| Dependency | Purpose | License | Repository / Origin | Integration Notes |
|:---|:---|:---|:---|:---|
| **FastAPI** | High-performance asynchronous API framework | MIT | [github.com/fastapi/fastapi](https://github.com/fastapi/fastapi) | Powers core REST endpoints |
| **Uvicorn** | ASGI server implementation | BSD-3-Clause | [github.com/encode/uvicorn](https://github.com/encode/uvicorn) | Local and production async serving |
| **Pydantic / Pydantic-Settings** | Data validation and settings management | MIT | [github.com/pydantic/pydantic](https://github.com/pydantic/pydantic) | Typed schema enforcement & `.env` parsing |
| **HTTPX** | Asynchronous HTTP client with connection pooling | BSD-3-Clause | [github.com/encode/httpx](https://github.com/encode/httpx) | Provider communication with AgentRouter |
| **SymPy** | Symbolic mathematics and algebraic equation solver | BSD-3-Clause | [github.com/sympy/sympy](https://github.com/sympy/sympy) | Deterministic algebraic verification in Socratic Tutor |
| **PyPDF / PyMuPDF** | Document stream extraction and layout detection | Apache 2.0 / AGPL (or fallback text reader) | [github.com/py-pdf/pypdf](https://github.com/py-pdf/pypdf) | Marksheet and student notes preprocessing |
| **Motor / PyMongo** | Asynchronous MongoDB driver | Apache 2.0 | [github.com/mongodb/motor](https://github.com/mongodb/motor) | Persistent document and event storage |
| **Pytest / Pytest-Asyncio** | Automated testing suite | MIT | [github.com/pytest-dev/pytest](https://github.com/pytest-dev/pytest) | Rigorous verification of ML, BKT, and IRT algorithms |
| **React / Next.js** | Client frontend user interface | MIT | [github.com/vercel/next.js](https://github.com/vercel/next.js) | Dynamic 11-tab educational dashboard |
